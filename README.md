# التوكيل للصيانة — الموقع الرسمي (Production Website)

موقع ويب ساكن (Static Website) متكامل واحترافي لخدمات صيانة وإصلاح الأجهزة المنزلية والكهربائية، جاهز للنشر المباشر على **GitHub Pages**.

## 🌟 مميزات المشروع
- **اسم البراند الموحد:** التوكيل للصيانة.
- **القائمة الموسعة الذكية (Services Mega Menu):** قائمة منسدلة عملاقة على الشاشات الكبيرة مقسمة لأعمدة واضحة، وقائمة أكورديون تفاعلية سلسة على شاشات الهواتف.
- **15 صفحة خدمة متخصصة:** كل خدمة لها صفحة ومقال كامل يحتوي على أشهر الأعطال، التشخيص، خطوات الإصلاح، لماذا التوكيل، قطع الغيار، والأسئلة الشائعة (FAQ).
- **أرشيف المعرفة الكامل (20 مقالاً):** الحفاظ الكامل على كافة مقالات الأرشيف العشرين وصورها وتنسيقها.
- **شعارات الماركات الرسمية:** استخدام شعارات المتجهات الرسمية (SVG) لكبرى العلامات التجارية (إل جي، سامسونج، كريازي، توشيبا، شارب، فريش، أريستون، يونيفرسال، وايت بوينت، زانوسي).
- **أرقام الاتصال الموحدة:**
  - الهاتف: `01276042120`
  - واتساب: `https://wa.me/201276042120`
- **متجاوب 100% (Responsive):** تم اختباره على مختلف دقات الشاشات (320px, 375px, 414px, 768px, 1024px, Desktop).
- **خالٍ من أي ادعاءات وكالة رسمية:** صياغة مهنية دقيقة متوافقة مع المتطلبات القانونية والتنظيمية.
- **مهيأ للنشر المباشر:** يحتوي الجذر على `index.html` وملف `.nojekyll` لضمان عمل كافة المسارات والصور.

## 🚀 طريقة الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub.
2. ارفع كافة محتويات هذا المجلد مباشرة إلى الفرع الرئيسي (`main`).
3. انتقل إلى إعدادات المستودع `Settings` -> `Pages`.
4. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط `Save`.
5. سيعمل موقعك فوراً على الرابط المخصص!
